# Монитор мест на экскурсию «АВТОВАЗ — путь успеха!»

Монитор проверяет наличие мест на экскурсию **21.08.2026** каждые 15 минут и пишет в Telegram:

- сразу после обнаружения нового статуса или изменения числа мест;
- около 09:00 и 21:00 по московскому времени, подтверждая, что монитор включён;
- при первой ошибке сайта или разметки и после восстановления.

## Подготовка Telegram

Токен, отправленный в переписку, необходимо отозвать:

1. Откройте `@BotFather`.
2. Выполните `/revoke` и выберите нужного бота.
3. Получите новый токен. Не добавляйте его в файлы проекта и не отправляйте в переписку.

Боту уже нужно быть разрешено писать вам: для этого достаточно однажды нажать «Запустить» или отправить ему `/start`.

## Запуск в GitHub

1. Создайте **приватный** репозиторий на GitHub.
2. Загрузите в него этот проект и сделайте рабочей ветку `main` веткой по умолчанию.
3. Откройте `Settings → Secrets and variables → Actions`.
4. Создайте repository secret `TELEGRAM_BOT_TOKEN` со свежим токеном от `@BotFather`.
5. Создайте repository secret `TELEGRAM_CHAT_ID` с числовым идентификатором вашего Telegram-чата.
6. Откройте `Actions → Monitor excursion availability → Run workflow`.
7. Убедитесь, что workflow завершился зелёным и бот прислал стартовый статус.

Токен и chat ID поступают только в шаг проверки через GitHub Secrets. Они не сохраняются в коде, Git-истории или файле состояния.

## Как работает расписание

GitHub Actions запускает `.github/workflows/monitor.yml` по cron-выражению `*/15 * * * *`. Обычно изменение обнаруживается в течение 15 минут, но GitHub иногда задерживает плановые задания на несколько минут.

Контрольное сообщение отправляется первым фактическим запуском в интервале 09:00–09:59 и 21:00–21:59 по Москве. Это не создаёт четыре сообщения за час: отправленный временной слот сохраняется в `state/status.json`.

## Проверка локально

Для тестов токен не нужен:

```bash
python3 -m unittest discover -s tests -v
```

Для реального локального запуска задайте переменные только в текущем терминале:

```bash
export TELEGRAM_BOT_TOKEN="новый-токен"
export TELEGRAM_CHAT_ID="числовой-chat-id"
python3 run_monitor.py
```

Не сохраняйте эти команды с реальными значениями в файлах или истории Git.

## Остановка

Откройте репозиторий на GitHub, перейдите в `Actions → Monitor excursion availability`, откройте меню workflow и выберите `Disable workflow`.

## Файл состояния

`state/status.json` хранит последний обработанный статус и последний отправленный утренний или вечерний слот. Workflow коммитит файл только при изменении статуса либо после контрольного сообщения. Секретов в файле нет.
