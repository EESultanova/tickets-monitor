# Монитор мест на экскурсию «АВТОВАЗ — путь успеха!»

## Цель

Автоматически проверять наличие мест на экскурсию 21 августа 2026 года и уведомлять пользователя в Telegram. Монитор должен работать независимо от домашнего компьютера.

## Источник данных

- Страница: `https://xn----7sbaa5baman5bedhc2a0n.xn--p1ai/samara/sbornye-ekskursii/44884-avtovaz-put-uspekha-2026`
- Искомая дата: `21.08.2026`
- На момент проектирования карточка этой даты содержит статус `Мест нет`.

## Архитектура

Решение состоит из небольшого Python-приложения без сторонних библиотек и workflow GitHub Actions.

1. GitHub Actions запускает монитор каждые 15 минут и вручную через `workflow_dispatch`.
2. Монитор скачивает HTML страницы с тайм-аутом и понятным `User-Agent`.
3. Парсер находит карточку расписания с точной датой `21.08.2026` и извлекает текст наличия мест.
4. Нормализованный результат сравнивается с последним сохранённым состоянием.
5. При изменении статуса Telegram получает сообщение с новым статусом, временем проверки и ссылкой на экскурсию.
6. В 09:00 и 21:00 по часовому поясу `Europe/Moscow` Telegram получает контрольное сообщение о том, что монитор работает, вместе с текущим статусом.
7. Если состояние изменилось, workflow сохраняет обновлённый файл состояния в репозитории. Обычные проверки без изменений не создают коммиты.

## Статусы

- `sold_out` — карточка содержит `Мест нет`.
- `available` — карточка содержит `Осталось N мест`, другую явную информацию о доступности либо активную кнопку бронирования.
- `unknown` — дата найдена, но статус нельзя надёжно распознать.
- `date_missing` — карточка требуемой даты отсутствует.
- `fetch_error` — страницу не удалось получить.

Первый успешный запуск отправляет стартовое сообщение с текущим статусом. Последующие сообщения об изменениях отправляются только при переходе между нормализованными статусами или при изменении указанного числа мест.

## Уведомления

### Изменение

Сообщение содержит дату экскурсии, прошлый и новый статусы, число мест при наличии, время по Москве и ссылку на бронирование. При появлении мест сообщение визуально выделяется эмодзи.

Изменение обнаруживается на ближайшей проверке: обычно не позднее 15 минут после публикации на сайте. GitHub Actions может запустить плановую задачу с небольшой задержкой.

### Контрольное сообщение

В 09:00 и 21:00 по Москве отправляется сообщение вида: монитор включён, последняя проверка успешна, текущий статус — такой-то. Если плановый запуск GitHub Actions задержался, сообщение придёт после фактического старта задания.

### Ошибки

Однократная ошибка загрузки или разбора фиксируется в логах. Telegram получает предупреждение при первом переходе в ошибочный статус, но одинаковая ошибка не повторяется каждые 15 минут. После восстановления отправляется сообщение о возвращении к нормальной работе.

## Состояние

Файл состояния хранит только технические данные: нормализованный статус, исходный текст статуса, число мест и время последней успешной проверки. Секреты в него не записываются.

Workflow получает разрешение `contents: write` и коммитит файл состояния только при фактическом изменении. Для предотвращения конфликтов параллельные запуски объединены в одну concurrency-группу.

## Безопасность и конфигурация

В GitHub Secrets хранятся:

- `TELEGRAM_BOT_TOKEN` — новый токен после отзыва опубликованного токена;
- `TELEGRAM_CHAT_ID` — идентификатор Telegram-чата.

Токен не выводится в логи и не хранится в репозитории. Опубликованный в переписке токен должен быть отозван через `@BotFather` до запуска production-монитора.

## Тестирование

Автоматические тесты проверяют:

- распознавание `Мест нет`;
- распознавание `Осталось N мест` и извлечение числа;
- отсутствие искомой даты;
- неизвестную разметку карточки;
- решение об отправке сообщения при первом запуске и смене статуса;
- отсутствие дублирующих сообщений;
- контрольные сообщения только в 09:00 и 21:00 по Москве;
- отсутствие Telegram-вызовов в тестовом режиме.

Workflow отдельно запускает тесты перед выполнением проверки. Ручной запуск используется для финальной проверки после добавления GitHub Secrets.

## Не входит в первую версию

- мониторинг других дат и экскурсий;
- веб-интерфейс;
